refuses `REFCORE-UNSPECIFIED <section>: <question>` there. L §8.4 ("What isn't defined is refused") refuses a
case no rule reaches; refcore keeps the marker at each such site, as the list of open edges. 4 sites. Generated by

A minimal text is the lines added to a model with the usual header (`model`, `tally 2`, `on`, `start`, `end`), a
source `s` and `unit PLN: currency minor 0.01`; `V:` is a version with `cite`, `governs` and `known`; ` ⏎ `
separates lines; `…` in a question is filled in at run. A test named beside a text prints that refusal; a text
with no test is a sketch of the construct that reaches the site, not a run text.
