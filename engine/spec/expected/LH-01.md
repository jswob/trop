## Arithmetic

The case's own checks (§ Transcription notes) cover A, B and CFR Ex. 2's loss split. The others, worked one line at a time:

```
$ python3 -c "from decimal import Decimal as D; print(D('158')-D('125'), (D('158')-D('125'))*100/100)"
33 33
$ python3 -c "from decimal import Decimal as D; print(D(2750)+D(50)*(D(5000)-D(4000))/D(100), D(1125)+D(25)*(D(5000)-D(4000))/D(100))"
3250 1375
$ python3 -c "from decimal import Decimal as D; print(D(90)+(D(100)-D(80)), D(70)+(D(100)-D(80)))"
110 90
$ python3 -c "from decimal import Decimal as D; print(D(10000)-D(9000), (D(10000)-D(9000))/100*100)"
1000 1000
$ python3 -c "from decimal import Decimal as D; print(D(1000)/D(100)*D(50))"
500
```

The fourth line gives CFR Ex. 1's loss and its disallowed part (all 100 shares matched), so its deductible part is 0. The fifth gives C's $10 loss per share × 50 shares, for each of the first two February lots.
