# RC-07 expected values

Model: `models/RC-07.tally`. Case: `tmp/verification/cases/RC-07.md`.

Locators name the case file's heading `## Published answer`, the bold form name under it and the line, with the front matter's `published_answers` entry by `name`. Every ask runs `with law 2025-12-31`. The model has no axes.

## Readings

- **Whole dollars.** Every line that multiplies is rounded with `round(x, 1, half-up)`, the p. 23 rule ("drop amounts under 50 cents and increase amounts from 50 to 99 cents to the next dollar"). The scenario rounds the same way.
- **Standard deduction.** Line 12e is `std_ded[single]` = 15,750, from the instructions (p. 6) and the form's own margin. The scenario enters 15,000 (§ Transcription notes, "Line 12e standard deduction: 15,000 against $15,750"), so lines 14, 15, 16, 18, 22, 24 and 37 come out different from the printed figures. Both are given below, each with the one-liner that produces it.
- **Blank lines are 0**, as rows of `entry`. Five lines and W-2 box 7 aren't listed in the case, so they are 0 as assumed rows (`model_assumptions`).
- **Knowledge.** The scenario's entries are a composed case's stipulations, so `ats12_entries` is now known from the model's `on` date, 2026-10-18, like `model_assumptions`. Form 7217 (December 2024) is dated only by its month, so `f7217_2024` is known from 2024-12-31. Every ask's cut is `on`, so each row is still read, and no value moved.
- **Form 7217 column (e)** was a bound in round 1. It is a missing method, not a step out of reach (§5.17), so it is now a hole rule, `f7217_col_e`, with its line B total `f7217_be` summing it.
