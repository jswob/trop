## The share readings, worked

The exact shares: `python3 -c "from fractions import Fraction as F; print(F(2000,3000), F(1000,3000), F(469*2,3), F(469,3), F(300*2,3), F(300,3))"` → `2/3 1/3 938/3 469/3 200 100`. Rounded half up to the cent, 938/3 and 469/3 give 312.67 and 156.33 (case check `print(round(469*2/3, 2), round(469/3, 2))` → `312.67 156.33`).

The percentages and the shares used: `python3 -c "from decimal import Decimal as D, ROUND_HALF_UP as H, ROUND_DOWN as R; print((D(2000)/D(3000)).quantize(D('0.0001'),H), (D(2000)/D(3000)).quantize(D('0.0001'),R), (D(1000)/D(3000)).quantize(D('0.0001'),H), (D(2000)/D(3000)*100).quantize(D('0.01'),R), (D(1000)/D(3000)*100).quantize(D('0.01'),R), (D(2000)/D(3000)*100).quantize(D(1),R), (D(1000)/D(3000)*100).quantize(D(1),R))"` → `0.6667 0.6666 0.3333 66.66 33.33 66 33`

The other two options: `python3 -c "from decimal import Decimal as D, ROUND_HALF_UP as H, ROUND_DOWN as R; from fractions import Fraction as F; c=D('0.01'); print([(n, (s*469).quantize(c,H), (t*469).quantize(c,H), (s*300).quantize(c,H), (t*300).quantize(c,H)) for n,s,t in (('half_up',D('0.6667'),D('0.3333')),('printed',D('0.6666'),D('0.3333')))])"` → `[('half_up', Decimal('312.68'), Decimal('156.32'), Decimal('200.01'), Decimal('99.99')), ('printed', Decimal('312.64'), Decimal('156.32'), Decimal('199.98'), Decimal('99.99'))]`

`python3 -c "from decimal import Decimal as D; print(D('312.68')+D('200.01'), D('156.32')+D('99.99'), D('312.64')+D('199.98'), D('156.32')+D('99.99'))"` → `512.69 256.31 512.62 256.31`

`python3 -c "from decimal import Decimal as D; print(D('512.69')-100, D('512.62')-100, D('512.69')+D('256.31'), D('512.62')+D('256.31'), 469+300)"` → `412.69 412.62 769.00 768.93 769`
