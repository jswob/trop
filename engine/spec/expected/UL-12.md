**Axis `ul12_pct`.** The page prints the shares to two decimals and doesn't say how it rounds them. The printed 16.67 is the `half-up` line:

```
$ python3 -c "from fractions import Fraction as F; print(float(F(1000000,6000000)*100))"
16.666666666666668
```

**The 55 % cell.** The English deductible-debt cell for the fund prints "(300,000 x 55 %)". The model takes the 2023/2024 table value, 20 per cent off, so 80 %, which gives the printed 240,000. That matches the Norwegian page's "(300 000 x 80 %)" (case transcription note "Inconsistent percentage on the English page").
