What took the most reading:
- How a key's "refusal (missing X)" maps to Tally. Tally's way to say a fact is missing is a hole with its question (NUM-01 a, ASK-03 a); a refusal code comes only from the engine (ASK-03 b, through `RUN-PLACE`).
- "Partial" across a sum (ASK-02), and the fact that Tally has no refusal for a question asking for a choice (ASK-04).
- §3.4 `prices … by` is defined only by its reads, so I used a def keyed by year as the price index (NUM-06). The reads `cpi[d]` / `cpi[2025]` define its meaning.
- I checked `prorata rest largest` against "in the order listed" (NUM-05). With equal weights every remainder is equal, so ties go by index order: same.
